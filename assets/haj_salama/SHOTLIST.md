# Haj Salama — image shot list

Every image here becomes real painted detail the animation can use instead of bending pixels.
Generate them as **edits of `refs/ref10.png`** (upload it, then paste the prompt), in the same chat
or project you used for the original references, so the style stays identical.

## Rules for every image (paste once at the top of the chat)

> Edit the uploaded image. Keep EVERYTHING identical — same character, same face proportions, same
> red-and-white shemagh and black agal, same beige shirt, same chair, desk, tablet, lighting, camera
> angle, framing, image size and painting style — and change ONLY what I describe. Do not redraw
> anything else. Keep the green screen green.

Save each result as the file name given (PNG, full size), into `assets/haj_salama/gen/`.
If a result changes the face or framing noticeably, regenerate — matching beats beauty.

## Tips

- Do A and B first. With those alone the mouth and blinks become painted instead of warped.
- If the service drifts after many edits, start a new chat, upload `ref10.png` again and repeat the rules.
- Small differences in colour are fixable here; different face shapes are not.
